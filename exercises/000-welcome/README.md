# `000` Welcome to Master Python: Classes and OOP

We are very excited to have you here! 🎉

In this LearnPack you will design your own classes. Each exercise introduces one object-oriented concept with an example and then asks you to apply it. The last exercise combines everything in a small shopping cart.

## What will you practice?

- **Exercises:** `001-017`
- **Focus:** classes and instances, `__init__`, `__str__`, `__repr__`, `__eq__`, class attributes, inheritance and `super()`, polymorphism, `@staticmethod`, `@classmethod`, `@property`, composition, abstract classes, `@dataclass`, generators and iterators
- **Difficulty:** intermediate

## How to work on each exercise

1. Read the instructions.
2. Write your solution in `app.py`.
3. Click **Run** to see what your code prints.
4. Click **Test** and iterate until every test passes.
